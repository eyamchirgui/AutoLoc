# AutoLoc 
## Objectifs du projet
AutoLoc est une application de gestion de location de véhicules.

## Acteurs identifiés
- Client : recherche et réserve des véhicules
- Agent d'agence : gère les réservations et les véhicules de son agence
- Responsable d'agence : supervise les agents et les opérations de son agence
- Administrateur : gère l'ensemble du système (utilisateurs, agences, etc.)
